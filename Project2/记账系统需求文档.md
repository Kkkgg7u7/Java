# 记账系统需求文档

## 1. 项目概述
本项目采用 `Spring Boot` 架构，实现一个简单的 `Web 记账系统`。

系统面向个人用户，支持日常收入、支出记录，以及账户余额汇总、每月收支统计等基础功能。

项目定位如下：
- 不是复杂企业级财务系统
- 是一个适合课程实验开发的基础记账 Web 应用
- 重点体现增删改查、分层架构、前后端协作和统计展示能力

---

## 2. 项目目标
实现一个具备以下能力的 Web 应用：
- 用户登录
- 记账记录的增删改查
- 支出/收入分类管理
- 多账户管理
- 账户金额汇总
- 每月收支统计
- 收支占比图表展示

---

## 3. 系统角色

### 3.1 普通用户
系统主要使用者，可以：
- 登录系统
- 管理自己的账户
- 记录收入和支出
- 查询和修改自己的账单
- 查看统计信息

---

## 4. 功能需求

### 4.1 用户登录功能
为了避免其他人随意操作他人账目，系统需要提供基础登录功能。

功能要求：
- 提供登录界面
- 用户输入账号和密码进行登录
- 登录成功后，系统自动识别当前用户
- 后续记账数据自动绑定当前用户 `user_id`
- 未登录用户不能访问记账数据

简化范围：
- 暂不接入微信、支付宝等第三方登录
- 仅实现本地账号密码登录

### 4.2 记账记录管理
系统核心功能是对收入/支出记录进行管理，支持标准 CRUD。

功能包括：
- 新增记录
- 删除记录
- 修改记录
- 查询记录列表
- 按条件筛选记录

记录类型：
- 收入
- 支出

### 4.3 账户管理
用户可以维护多个账户，用于记录资金来源或去向。

支持的账户类型示例：
- 微信账户
- 支付宝账户
- 银行卡账户
- 现金账户

功能包括：
- 新增账户
- 删除账户
- 修改账户信息
- 查询账户列表
- 统计不同账户总余额

说明：
- 不需要真正连接微信、支付宝 API
- 账户数据由用户自行创建和录入

### 4.4 分类管理
记账记录需要支持分类，用于区分消费或收入用途。

示例分类：
- 餐饮
- 交通
- 购物
- 工资
- 奖金
- 其他

功能要求：
- 记账时通过下拉框选择分类
- 可预置常用分类
- 如有余力，可支持分类的增删改查

### 4.5 汇总统计功能
为了体现系统的数据分析能力，需要提供统计汇总功能。

功能包括：
- 不同账户总余额统计
- 每个月收入统计
- 每个月支出统计
- 每月结余统计
- 收入/支出占比图展示

建议图表：
- 饼图：收支分类占比
- 柱状图或折线图：每月收支变化趋势

## 5. 数据项设计

### 5.1 记账记录表
| 字段名 | 含义 | 类型 | UI建议 |
|---|---|---|---|
| id | 唯一标识 | Long | 不显示 |
| user_id | 操作人ID | Long | 自动获取，不显示 |
| type | 收/支类型 | Integer | 0-支出，1-收入；单选框/开关 |
| amount | 金额 | Decimal(10,2) | 输入框 |
| category | 消费/收入分类 | String | 下拉选择器 |
| account_type | 支付/收款方式 | String | 下拉选择器 |
| record_date | 发生时间 | Date | 日期选择器 |
| remark | 备注 | String | 多行文本框 |
| create_time | 系统录入时间 | DateTime | 自动生成 |

### 5.2 建议补充的数据表
为了支撑“表多一些、便于发挥”，建议至少设计以下几张表：

#### 1. 用户表 `user`
字段建议：
- id
- username
- password
- nickname
- create_time

#### 2. 记账记录表 `record`
字段参考上表

#### 3. 账户表 `account`
字段建议：
- id
- user_id
- account_name
- account_type
- balance
- create_time

#### 4. 分类表 `category`
字段建议：
- id
- user_id
- category_name
- type
- create_time

这样系统表结构更完整，也更符合实验要求。

## 7. 非功能需求
- 使用 `Spring Boot` 实现后端
- 前后端分离或半分离均可
- 系统需具备基本页面交互能力
- 数据持久化到数据库
- 界面简洁易用，适合课程展示
- 代码按分层架构组织：`Controller / Service / Dao / Entity`
